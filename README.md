# 🍽️ Kaake Da Dhabha – Restaurant Website

A responsive restaurant website built using **HTML and CSS** as a frontend web development project.

## 📌 About the Project

**Kaake Da Dhabha** is a restaurant-themed website designed to present a food business through a clean and responsive web interface.

The website includes a navigation bar, restaurant hero section, services section, client showcase, contact form, and responsive layouts for smaller screens.

## ✨ Features

* Responsive navigation bar
* Restaurant hero/landing section
* Food ordering call-to-action button
* Services section
* Client/brand showcase
* Contact form UI
* Responsive design for smaller screens
* Custom images and background sections
* Separate CSS files for desktop and responsive layouts

## 🛠️ Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* Google Fonts

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Shubhamnarnoliya/project1.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation are required.
